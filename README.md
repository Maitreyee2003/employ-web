# EmpHub – Employee Management System

EmpHub is a web-based Employee Management System developed using Java technologies. It helps administrators efficiently manage employee records through a simple and user-friendly interface.

## 🚀 Features

- **Admin Authentication:** Admin login authentication to restrict access to management pages.
- **Add Employee:** Add new employee records to the database.
- **View Employees:** Display employee information.
- **Update Employee:** Modify existing employee details.
- **Delete Employee:** Remove employee records.
- **Search Employees:** Find employee records easily.
- **Sorting:** Organize employee records.
- **Pagination:** Navigate through employee records efficiently.
- **CSV Export:** Export employee data in CSV format.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Java | Backend development |
| JSP | Dynamic web pages |
| Servlets | Request handling and application logic |
| JDBC | Database connectivity |
| MySQL | Database management |
| HTML & CSS | Frontend design |
| JavaScript | Client-side functionality |
| Maven | Project and dependency management |

## 🏗️ Project Architecture

The application follows the **MVC (Model-View-Controller)** and **DAO (Data Access Object)** design patterns.

- **Model:** Represents employee data.
- **View:** JSP pages display the application interface.
- **Controller:** Servlets handle user requests and application flow.
- **DAO:** EmployeeDAO manages database operations using JDBC.

## ⚙️ Installation and Setup

Follow these steps to run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Maitreyee2003/employ-web
   ```

2. Open the project in Eclipse or another Java IDE that supports Maven projects.

3. Configure your MySQL database and update the database connection details in the project's JDBC configuration.

4. Ensure the required MySQL database and employee table are available.

5. Build the project using Maven.

6. Configure and run the application on a compatible Apache Tomcat server.

7. Open the application in your browser using the local server URL.

## 📂 Main Functionalities

The system provides complete CRUD (Create, Read, Update, Delete) operations for employee management, along with authentication, searching, sorting, pagination, and CSV export.

## 🎯 Project Objective

The main objective of EmpHub is to simplify employee record management by providing a centralized web-based application with organized data handling, database connectivity, and admin access control.
